# Lab Notebook

Experiments, prototypes, and half-finished ideas. Things that graduate get their own repository.

This repository is intentionally not a product. It is a working notebook for small technical ideas that are useful enough to try, but not necessarily useful enough to deserve their own repo yet.

## Status

Experiments live in one of three places:

- **active/** — currently being explored.
- **abandoned/** — learned something, stopped there.
- **graduated/** — became useful enough to move into a proper project.

Nothing here should be assumed stable unless the experiment says otherwise.

## Current notebook

| Experiment | Status | Notes |
|---|---|---|
| File aging model | active | Small PowerShell prototype for classifying stale files by age. |
| Terminal color gradient | abandoned | Solved the important problem, which was making a folder list unnecessarily colorful. |
| Folder review tooling | graduated | Moved into `raiders-of-the-lost-archive`. |

## Rules

1. Small is fine.
2. Broken is fine if the notes explain what was learned.
3. Useful experiments should eventually leave.
4. Rewriting something because the first version was ugly is not architecture.
5. The notebook is never finished.
