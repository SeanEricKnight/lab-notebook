# Terminal Color Gradient

**Status:** abandoned

Experimented with assigning a separate console color to each folder while keeping the overall list roughly ordered from warm to cool.

It worked well enough for the original use case.

Further research was halted after it became clear that the terminal does not become materially more informative after the eighth color.

### Learned

- Visual grouping is genuinely useful.
- Random colors are not.
- There is a narrow line between "easy to scan" and "PowerShell has entered a carnival."
